# 버거 타워! 🍔

상단을 좌우로 움직이는 실제 음식 사진 질감의 재료를 클릭해 고정된 아래 참깨빵 위에 쌓는 무한 스태킹 게임입니다. 무게 중심이 벗어나면 타워가 무너지며, 원하는 만큼 쌓은 뒤 **마지막 빵 올리기** 버튼으로 완성할 수 있습니다.

재료 이미지는 투명 여백을 잘라 실제 식재료 표면이 서로 맞닿고 살짝 눌려 쌓이는 것처럼 보이도록 조정되어 있습니다.

세로형 게임 화면을 사용하며, 타워가 높아질수록 아래빵을 고정점으로 햄버거 전체가 자동 축소되어 모든 층이 계속 화면 안에 표시됩니다.

공중에서는 재료 원형을 유지하고, 착지하면 세로로 눌리면서 아래 재료 중심 쪽으로 모여 서로 깊게 겹칩니다. 배경과 인터페이스는 밝은 무채색 기반의 미니멀 스타일입니다.

모든 재료의 질량은 동일하게 1kg입니다. 각 층에서는 그 위에 놓인 모든 재료의 위치를 동일한 비중으로 합산한 무게중심이 아래 재료의 지지면 안에 있어야 합니다. 재료 사이에는 빈틈이 생기지 않습니다.

처음에는 재료가 햄버거 가까운 낮은 레일에서 출발하고, 층수가 올라갈수록 출발 레일이 위로 이동해 낙하 거리가 길어집니다. 좌우 이동 및 낙하 속도는 10층마다 이전 구간의 1.5배가 됩니다. 착지한 재료는 깊게 겹치며 옆으로 퍼지고 접촉면에 부드러운 음식 그림자가 생깁니다.

자동 축소는 실제 타워 경계와 층수를 동시에 사용합니다. 22층부터 타워 전체와 움직이는 재료가 부드럽게 축소되며, 최소 22% 크기까지 줄어들어 높은 층에서도 아래빵과 꼭대기 재료가 모두 화면에 남습니다.

## 실행

별도 빌드가 필요 없는 정적 사이트입니다. `index.html`을 열거나 아래 명령으로 실행하세요.

```bash
npx serve .
```

## 조작

- PC: 게임 화면을 클릭해 재료 떨어뜨리기
- 모바일: 게임 화면을 터치해 재료 떨어뜨리기
- Space 또는 Enter 키로도 떨어뜨릴 수 있습니다.
- 원하는 시점에 **마지막 빵 올리기** 버튼을 누르면 층수가 확정됩니다.
- 일시정지: 상단 버튼 또는 Space

## GitHub / Vercel 배포

1. 이 폴더 전체를 GitHub 저장소에 올립니다.
2. Vercel에서 **Add New Project**를 선택하고 저장소를 연결합니다.
3. Framework Preset은 **Other**, Build Command는 비우고 Output Directory는 `.`으로 둡니다.
4. Deploy를 누릅니다.

외부 이미지 없이 HTML, CSS, Canvas JavaScript로 구성되어 있습니다.
